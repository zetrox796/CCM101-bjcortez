# Checkpoint 3 – Identify Cloud Infrastructure Components

## Compute Resources
* **Purpose:** Compute resources process data. They run programs.
* **Importance in Cloud Computing:** Cloud providers rent processing power to users. Users scale this power to match their needs. 
* **KillerCoda Environment:** The terminal uses an Intel Xeon E312xx processor. It has one CPU core. The system provides 1.9Gi of total RAM. RAM is active working memory.

## Storage Resources
* **Purpose:** Storage resources hold data. They save files permanently.
* **Importance in Cloud Computing:** Cloud storage lets users save files safely online. Users pay only for the space they need.
* **KillerCoda Environment:** The server uses a main drive named `/dev/vda1`. This drive holds 19G of data. The system mounts this drive to the root directory (`/`). The root directory is the top folder in Linux. 

## Networking Resources
* **Purpose:** Networking resources connect computers. They send data between systems.
* **Importance in Cloud Computing:** Networks allow users to reach cloud servers from anywhere. They let different cloud services work together. 

## Operating System
* **Purpose:** The operating system manages computer hardware.And runs software programs.
* **Importance in Cloud Computing:** The operating system provides a base platform. As it supports all cloud applications.
* **KillerCoda Environment:**  Server runs Ubuntu 24.04.4 LTS.  operates on Linux kernel version 6.8.0-138-generic. kernel is the core program of the operating system.
