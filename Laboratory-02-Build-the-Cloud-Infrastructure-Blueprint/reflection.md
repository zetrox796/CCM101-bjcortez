# Checkpoint 7 – Mission Reflection 

Networking is the most important cloud infrastructure component. As the cloud relies entirely on remote access. Users cannot reach those servers without a network. A network connects compute, storage, and identity systems together.  It makes the entire cloud work as one single unit. 

Linux acts as the foundation for most of these cloud servers as it manages server hardware efficiently.  Linux provides powerful command-line tools, these tools let engineers control the system quickly. Linux is also open-source software. Cloud providers do not pay licensing fees to use it. They pass these exact savings to their users. This keeps cloud computing costs low.

Technical documentation acts as a clear blueprint before engineers deploy infrastructure.  Good documents align the whole team. They serve as a guide for future system updates. Documentation also helps teams solve problems faster when systems fail.
