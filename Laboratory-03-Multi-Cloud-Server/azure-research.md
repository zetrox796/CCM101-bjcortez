# Checkpoint 2 - Microsoft Azure Research

## Brief Overview
Microsoft Azure is a public cloud platform. 

## Global Infrastructure
Azure is a massive global network. Microsoft places data centers in regions around the world that are connected through a dedicated network.

## Cloud Management Console
Azure portal is a single web console where you build, manage, and monitor your apps .

## Core Services
1. **Azure SQL Database:** Provides a managed database service.
2. **Azure App Service:** Hosts web apps and APIs.
3. **Azure Virtual Machines:** Hosts Windows or Linux servers.
4. **Azure Blob Storage:** Stores massive amounts of unstructured data.

## Advantages
1. Comprehensive compliance coverage.
2. Strong integration with Microsoft products.
3. Robust hybrid cloud features.

## Typical Enterprise Use Cases
Enterprises use Azure for identity management, run Windows Server workloads, build hybrid cloud environments.
