# Checkpoint 4 – Cloud Platform Recommendation Challenge

## Client A – Startup Company
**Recommended Platform:** Amazon Web Services (AWS)

**Explanation:**Because it offer a flexible pay-as-you-go pricing models for startup. This model also keep the initial cost low, The platforms scale easily to handle the rapid user growths when they expand in the future. AWS feature a broad ecosystem to supports mobile application.

**Recommended Services:** Amazon EC2, Amazon RDS, and Amazon S3.

## Client B – University
**Recommended Platform:** Microsoft Azure

**Explanation:** Because it integrate natively with existing Microsoft tool. Azure provide strong hybrid cloud capabilities for large organizations that want to keeps their old systems. This native integrations reduce frictions during security review. The platform support seamless migration to the cloud.

**Recommended Services:**  Azure Blob Storage, Microsoft Entra ID, and Azure Virtual Machines.

## Client C – AI Research Company
**Recommended Platform:** Google Cloud Platform (GCP)

**Explanation:** GCP lead the market in high-performance computing and artificial intelligence and the platform offer a specialized Processing Units to trains models.GCP represent the top choice for AI research organization. Google provide superior tool for large machine learning workflows which require lot of compute power.

**Recommended Services:** Google Compute Engine,  Vertex AI, and Google Cloud Storage.

## Client D – Global E-Commerce Company
**Recommended Platform:** Amazon Web Services (AWS)

**Explanation:** Because it maintain the largest global infrastructure with a lot of available zone. This coverages makes sure of the maximum geographical distribution and enterprise-level resilience for global company. The platform manage demand peaks effectively with rapid scaling. 

**Recommended Services:**  Amazon CloudFront, Amazon EC2, and Amazon RDS.

## Checkpoint 6 – Multi-Cloud Decision Matrix 

| Business Requirement | Recommended Platform | Justification |
| :--- | :--- | :--- |
| **Startup Company** | Amazon Web Services (AWS) | Startups can already build their apps fast without spending a lot of money quickly. It also offer price that are cheap for small teams |
| **Enterprise Organization** | Amazon Web Services (AWS) | AWS has the largest global infrustructure which big companies need so their system doesnt crash during high demands. |
| **Microsoft Environment** | Microsoft Azure | Azure integrate perfectly with Windows tool. If a company use Active Directory already, it save them lot of times. |
| **AI / Machine Learning** | Google Cloud Platform (GCP) | GCP provide the best tools for artificial intelligences. It has specialized processors that trains machine learning models very fast. |
| **Kubernetes Deployment** | Google Cloud Platform (GCP) | Google originally created Kubernetes so GCP have the best supports for it. It make managing containers deployments much easier. |
| **Global Web Application** | Amazon Web Services (AWS) | AWS maintain many availability zone all over the world. This ensure your web apps stays online and load fasts for users everywhere. |
