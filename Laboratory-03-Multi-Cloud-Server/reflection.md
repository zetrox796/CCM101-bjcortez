# Mission Reflection


Cloud explorer mission gave me a lot of thoughts about the way modern cloud systems are built. Out of all the companies Google Cloud Platform made the biggest impression on me. That's because it handles engineering challenges in a very clear way. Especially when it comes to Kubernetes orchestration, which's the best in the industry and BigQuery, which is very strong when it comes to data analysis. Even though each of them has features, AWS, Azure and GCP are similar in some ways. They all have public cloud tools. These include compute instances that can grow as needed safe ways to store data, databases that are easy to manage and systems that keep things secure when it comes to user access. All of these run on a network of availability zones spread around the world. They have a pricing system that lets you pay only for what you use.

When I looked at situations that clients might have I realized that what the business needs is the most important thing when choosing a cloud platform. A cloud engineer can't just pick the one that's most popular. Instead the choices need to fit with the companys technology how much money they have how fast they need to grow and what kind of performance they need. Working as a Cloud Solutions Consultant taught me to ignore the marketing and instead look at the structures based on rules they have to follow where they're available and how strong the system is. I learned to balance money issues with the need for things to work all the time to fix business problems.

At the end this mission helped me a lot with my GitHub Cloud Computing Portfolio. It made my collection of projects grow from cloud plans into a full set of knowledge about multi-cloud designs. Adding organized Markdown notes tables that show how services connect and explanations for why certain choices were made turned my GitHub page into an engineering portfolio. This task really reminded me of the idea: to be, in charge of technology using smart thinking to make decisions instead of just going along with what everyone else is doing.
