# Checkpoint 2 - Google Cloud Platform (GCP) Research

## Brief Overview
Google Cloud Platform (GCP) is a collecion of cloud services. Google runs it on its internal infrastructure.

## Global Infrastructure
GCP spans multiple regions globally. Each region contains zones. A global fiber network connects them.

## Cloud Management Console
The Google Cloud Console provides a web interface. It includes tools for billing and API management.

## Core Services
1. **Google Kubernetes Engine (GKE):** Manages containerized applications.
2. **BigQuery:** Analyzes large datasets quickly.
3. **Google Compute Engine:** Offers customizable virtual machines.
4. **Google Cloud Storage:** Delivers secure object storage.

## Advantages
1. Strong data analytics capabilities.
2. Excellent machine tools.
3. High-performance global network.

## Typical Enterprise Use Cases
Businesses run complex data analytics on GCP. They develop machine learning models. They manage massive container deployments.
