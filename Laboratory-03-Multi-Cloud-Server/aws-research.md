# Checkpoint 2 - Amazon Web Services (AWS) Research

## Brief Overview
Amazon Web Services (AWS) is a cloud platform Amazon provides it and offers compute power, database storage, and content delivery.

## Global Infrastructure
AWS operates in multiple regions worldwide. Each region has availability zones and these zones have distinct data centers.

## Cloud Management Console
The AWS Management Console is a web interface that we use  to manage  AWS resources. It provides access to billing, monitoring, and security tools.

## Core Services
1. **AWS Lambda:** Runs code without provisioning servers.
2. **Amazon RDS:** Manages relational databases.
3. **Amazon S3:** Stores objects and files.
4. **Amazon EC2:** Provides virtual servers.

## Advantages
1. Global reach.
2. High reliability and uptime.
3. Large ecosystem of services.

## Typical Enterprise Use Cases
Companies use AWS for web hosting. They migrate legacy applications to it.
