# Checkpoint 7 - Mission Reflection

A host‑based firewall adds a second layer of defense. The host‑based firewall acts like a guard for the operating system blocking unauthorized traffic right at the server level. Even if hackers breach the network the host‑based firewall protects the server creating a strong defense in depth. A single failure of the host‑based firewall will not easily expose the system.

Open network ports act like unlocked doors. Attackers constantly scan these ports to find ways into our system. Closing unused ports removes these entry points shrinking the attack surface. With an attack surface fewer targets remain for hackers so administrators must carefully control ports to keep all threats out.

A database holds sensitive records and data. Leaving a database port to the internet invites constant danger from hackers who launch automated attacks from anywhere. They can. Destroy critical business data. Administrators must restrict database access to trusted internal servers isolating valuable information from public threat.

This mission completely changed my view, on server deployment. I saw the dangers of default settings. When a brand new server connects to the internet without protection bots scan for those exposed machines constantly. Security requires action. Engineers must secure the systems before deploying applications because waiting even a few minutes can cause data breaches.
