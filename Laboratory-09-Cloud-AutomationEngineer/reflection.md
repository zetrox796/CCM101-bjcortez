# Checkpoint 7 - Mission Reflection 

Automation is critical when you manage hundreds of servers because manual configuration takes far too much time. Humans often make mistakes. Automation ensures consistency everywhere. Automation allows the teams to scale operations instantly. Because computers run scripts faster than humans type commands, automation keeps businesses running smoothly without interruptions.

However automation carries risks. A single typo can cause damage. If you deploy a script to 1,000 servers you break all of them simultaneously. Automated errors spread faster. Bad code can delete databases in seconds. You must test scripts in environments before you deploy.

Writing a Bash script differs greatly from creating a Docker Compose YAML file. You write step‑by‑step instructions. You tell the operating system how to perform the task.. Creating a Docker YAML file works differently because you declare the final state you want. Docker figures it out. Bash focuses on the process. YAML focuses on the result.

My understanding of cloud computing grew a lot since the beginning of this semester. I began by building infrastructure. Then I learned how to deploy applications using containers and after that I explored security rules. The cloud is a system. I understand how software, servers and networks support each other to create something.

I enjoyed the Cloud Security Engineer role the most because it showed me how important it is to protect servers and control network access. Configuring firewall rules helped me understand that security measures can reduce the risk of connections. I also found the Cloud Automation Engineer role because it showed how scripts can simplify repetitive tasks and reduce manual work.
