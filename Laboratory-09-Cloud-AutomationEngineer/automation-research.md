# Checkpoint 2 - Research: The Language of Automation 

**Bash Script**
A bash script is a text file full of system commands. The system runs these commands in order. The `#!/bin/bash` shebang tells the system to use the Bash shell to read the file.

**Variables**
Programmers use variables to store data. A variable like `$BACKUP_DIR` saves time. It prevents typing mistakes. You update the value once if the folder path changes.

**Cron Job**
A cron job is a scheduled task in Linux. It runs scripts at exact times. This tool lets cloud operators automate repetitive tasks. It removes the need for human action.
